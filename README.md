# SmartCredit Website

A sleek, animated, responsive landing page for SmartCredit, showcasing funding solutions for hotels based on performance.

## 🌟 Features

- Smooth animated hero section with a line graph
- Scroll-triggered sticky glassy header
- Fully responsive layout
- Smart analysis & funding explanation steps
- Clean contact form (on Get Started page)

## 📂 Pages

- `index.html` – Main landing page
- `get-started.html` – Get Started form
- `style.css` – Unified styles and animations
